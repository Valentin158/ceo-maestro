# CEO Maestro en GitHub Actions

Flujo inicial sin secretos ni costos externos: ejecucion diaria y manual para producir un informe JSON de seis negocios.
No ejecuta agentes de IA ni consulta tableros aun. No publica ni contacta clientes.
GitHub Actions no es un servidor n8n permanente. La ejecucion programada puede retrasarse y depende de las cuotas del plan.
Subir el contenido de esta carpeta a un repositorio privado y comprobar la primera ejecucion en Actions.
